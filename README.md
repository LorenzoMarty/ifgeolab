# IFGeoLab - *⚠️ Projeto Legado*

O projeto **IFGeoLab** foi pensado como uma bolsa científica com intuito de desenvolver um laboratório digital de rochas e minerais com diferencial de uma visualização 3D das amostras.

## Funcionalidades

- CRUD de amostras e usuários
- Geração de provas aleatórias para praticar o conteúdo da geologia
- Visualização 3D das amostras
- Geração de pdf com informações das amostras
- Ranqueamento de colaboradores (usuários que cadastram amostras)
- Interface personalizável

## Diferencial

O sistema foi pensado para:
- Ser usado como ferramenta para auxiliar aulas de geográfia aplicadas ao Ensino Médio
- Mitigar a escassez de recursos através da visualização 3D
- Tornar aulas mais interativas e relevantes

## Arquitetura

Fluxo principal:

1. Estudante loga no sistema
2. Escolhe um mineral ou rocha
3. Analisa informações da amostra e visualiza seu modelo 3D
4. Estuda o acervo
5. Pratica o conhecimento adquirido com provas geradas automaticamente
